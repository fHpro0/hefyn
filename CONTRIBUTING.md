# Contributing

Issues and ideas are welcome.

For pull requests:

- Include this sentence in the PR description: "I have read the CLA in CLA.md and agree to its terms." See [CLA.md](CLA.md). It is required because hefyn is dual-licensed (AGPL and commercial); see [LICENSING.md](LICENSING.md).
- Run `bun run typecheck` and `bun run test` before opening the PR.
- Keep changes small and focused.
