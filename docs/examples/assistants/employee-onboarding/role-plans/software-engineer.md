# Software engineer, 30/60/90

## First 30 days: learn the system
- Complete security training (week 1) and set up the dev environment with the buddy.
- Read the architecture overview and the last three post-mortems.
- Ship a small, reviewed change to production (a "good first issue").
- Pair with two teammates on their current tickets.
- Meet: manager (weekly 1:1), buddy, product manager, tech lead, one person from support.

## Days 31-60: contribute
- Own a small feature end to end, including tests and the release.
- Join the on-call shadow rotation (observe only, no pager yet).
- Present a short learning from the first month in the team meeting.
- Meet: the platform team, security champion, a customer success manager.

## Days 61-90: own
- Lead a story of medium size; write the design note first and get it reviewed.
- Take the first on-call shift with a backup.
- Agree the goals for the next quarter with the manager; probation feedback talk is planned for month 3.

## Tools
GitHub, Jira, AWS (read-only first), Sentry, Datadog, 1Password.
